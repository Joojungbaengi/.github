- **술을 고르는 기준이 '취향'으로 옮겨가고 있습니다**

  - 농식품부·aT 「2025 주류산업정보 실태조사」는 국내 주류 시장을 '취향 소비' 중심의 재편으로 설명합니다. 저도주가 포함된 일반증류주는 출고량이 전년 대비 113.2%, 출고금액이 98.0% 늘었고, 혼술 비중은 30%를 넘었습니다.
  - 술을 고를 때 SNS를 참고한다는 응답이 60.7%, 20대 여성은 77.7%였습니다. '전통주 칵테일' 관련 소셜 언급량도 최근 1년간 6,000건을 넘어서며 하이볼·홈술이 주요 연관어로 나타났습니다.
  - 즉 무엇을 마실지 스스로 탐색하는 소비자는 늘었지만, 전통주는 종류와 양조 방식이 낯설어 "내 취향이 어느 술인지" 판단할 근거를 찾기 어렵습니다.

- **전통주는 '양'보다 '값'으로 성장하고 있습니다**

  - 국세통계연보 기준 2025년 전체 주류는 출고량 2,987,726kL(-5.2%), 출고금액 9조 6,951억 원(-3.6%)으로 모두 줄었습니다.
  - 같은 기간 전통주는 출고량이 22,284kL로 3.0% 줄었지만 출고금액은 1,459억 원으로 6.2% 늘었습니다. 리터당 출고금액은 5,980원에서 6,550원으로 약 9.5% 올랐습니다.
  - 다만 2024년 기준 전체 주류 시장에서 전통주가 차지하는 비중은 출고금액 1.4%, 출고량 0.73%에 머무릅니다. 가치를 인정받는 흐름은 확인됐지만, 제품을 알고 고르게 만드는 접점은 여전히 좁습니다.

- **체험 수요는 이미 증명됐지만, 갈 수 있는 곳은 한정적입니다**

  - 농식품부 '찾아가는 양조장' 방문객은 2025년 66만 명으로 전년 57만 명보다 15.8% 늘었고, 체험 예약은 4,820건(+31.7%), 실제 체험 방문은 3,225건(+35.7%)을 기록했습니다.
  - 반면 '찾아가는 양조장'으로 지정된 곳은 전국 69곳입니다. 체험하려면 그 지역까지 직접 이동해야 하므로, 시간과 거리의 제약을 받지 않는 디지털 체험 접점이 필요합니다.

- **그 접점의 효과가 가장 큰 지역이 경기도입니다**

  - 국세청 국세통계포털 2025년 지역특산주 출고 현황에서 경기도는 출고금액 268억 1,500만 원, 출고량 4,504kL로 모두 전국 1위입니다.
  - 그중 탁주(막걸리)가 198억 6,300만 원으로 지역 출고금액의 74.1%를 차지합니다. 경기미를 비롯한 지역 농산물을 원료로 삼는 주종이 중심이어서, 전통주 소비 확대가 지역 농산물 소비로 이어지는 구조입니다.

## 💡 Our Solution

#### 취향 진단 → 추천 → 양조 체험 → 수집이 하나로 이어집니다
- **술BTI**로 단맛·산미·바디·향·도수와 안주, 마시는 상황 등을 진단하고, 직접 조사해 구축한 경기도 전통주 데이터베이스에서 나에게 맞는 3종을 추천 근거와 함께 보여 줍니다. 후보를 좁히는 계산은 코드가 맡고 AI는 최종 선정과 설명만 담당하므로, 데이터베이스에 없는 술은 추천되지 않습니다.
- 추천받은 술의 **양조 과정을 AR로 직접 수행합니다.** 바닥이나 책상 위에 양조장이 놓이고, 원료를 집어 담고 쌀을 헹구고 고두밥을 부채질해 식히는 공정을 손으로 따라가며 순서와 원리를 익힙니다.
- 앱을 설치할 필요가 없습니다. **모바일 브라우저 링크 하나로** 3D·AR·손 인식·이미지 인식·생성형 AI가 모두 동작합니다. WebXR을 지원하는 기기에서는 증강현실로, 지원하지 않는 기기에서는 3D 자유시점 모드로 체험할 수 있습니다.
- 체험을 마치면 그 술이 **경기술 도감**에 담기고 경기술 지도에 스탬프가 찍힙니다. 아직 비어 있는 지역과 주종이 다음 탐색의 이유가 됩니다.

#### Business Model
- **양조장 B2B**: 직접 체험 공간을 마련하기 어려운 양조장을 위해 AR 양조 체험 콘텐츠 개발을 지원합니다.
- **판매·방문 연계**: 추천과 체험 직후의 관심을 지역 판매처, 온라인 판매 채널, 양조장 방문 예약으로 연결합니다.
- **공공·행사 공급**: 지자체 전통주 육성 사업, 축제·박람회 현장 체험 부스, 지역 관광 코스용 콘텐츠로 공급합니다.
- **취향 데이터 제공**: 익명으로 집계한 취향 분포와 지역·주종별 반응을 양조장의 제품 기획 자료로 제공합니다.

#### 현재 구현된 사항 (MVP)
- **술BTI 11문항**(객관식 10 + 자연어 1)으로 취향을 진단해 8종의 신선 유형을 판정하고, AI가 전통주 3종을 추천 근거와 함께 제시합니다.
- **경기도 전통주 22종 데이터베이스**(18개 시군, 탁주·약주·청주·증류식소주·과하주·과실주·리큐르)를 바탕으로 상세 화면에서 6가지 맛 척도, 원료와 양조 방식, 어울리는 안주, 비슷한 술 찾기를 제공합니다.
- **AR 양조 체험**은 평면을 인식해 양조장을 배치한 뒤 세미·침수·탈수·증자·냉각 → 혼합·발효 → 압착·여과·저온숙성·출고 공정을 진행합니다. 집기·휘젓기·부채질·주무르기 등 손동작으로 조작하며, 손 인식을 지원하지 않는 환경에서는 버튼으로 모든 공정을 끝까지 진행할 수 있습니다. (현재 냥이탁주 9만 구현되어 있음)
- **전통주 라벨 스캔**은 직접 학습한 YOLO11n 모델로 동림청주·천비향 약주·냥이탁주 9를 인식하며, 추론이 기기 안에서 끝나 촬영 이미지를 서버로 보내지 않습니다.
- **경기술 지도**에서 시군별 전통주와 양조장을 탐색하고, 체험을 마친 지역에 스탬프가 등록됩니다.
- **경기술 도감**에는 AR 양조를 끝까지 마친 술이 수집됩니다.

## ✅ Feature

#### 1. 술BTI — AI 취향 분석과 전통주 추천
- 단맛·산미·바디·탄산·향의 강도·도수와 안주, 마시는 상황을 묻는 객관식 10문항에 자유서술 1문항을 더해 취향을 구조화합니다.
- 규칙 기반 스코어링으로 22종을 상위 10종까지 좁힌 뒤, AWS Bedrock의 Claude Sonnet 4.5가 자연어 취향까지 고려해 3종을 고르고 이유를 작성합니다.
- 응답에 담긴 술 ID가 후보 목록에 실제로 있는지 검증해 없는 술을 지어내지 못하게 하고, 호출이 실패하면 규칙 기반 상위 3종으로 자동 전환해 결과가 비지 않도록 했습니다.

#### 2. AR 양조 체험 — 손으로 빚는 전통주
- WebXR `immersive-ar`의 hit-test로 평면을 인식해 바닥이나 책상에 양조장을 고정하고, Three.js로 원료와 시루·항아리·냉장창고를 배치합니다.
- MediaPipe HandLandmarker로 손 관절 21개를 추적해 **집기·휘젓기·부채질·주무르기·펴기**를 판정합니다. 히스테리시스와 연속 프레임 확인을 두어 손 떨림으로 인한 오작동을 걸러냅니다.
- AR 세션이 카메라를 독점하는 문제는 `camera-access`로 해결했습니다. AR 카메라 프레임을 256px로 줄여 초당 16회만 CPU로 내려받는 방식이라, 평면 인식과 손 인식을 한 화면에서 함께 돌리면서도 3D는 60fps를 유지합니다.
- 양조 공정은 술 하나에 레시피 파일 하나가 대응하는 구조여서, 덧술 횟수(단양주·삼양주·오양주)나 증류 공정 같은 주종별 분기를 데이터만 바꿔 추가할 수 있습니다.

#### 3. 전통주 라벨 스캔
- 전통주 3종의 사진으로 직접 학습한 YOLO11n을 ONNX로 내보내 ONNX Runtime Web(wasm)에서 실행합니다. 인식이 기기 안에서 끝나므로 촬영 이미지가 외부로 나가지 않습니다.
- 640×640 레터박스 전처리 → 추론 → 신뢰도 컷과 NMS를 거쳐, 같은 술이 3프레임 연속 잡히면 결과를 확정하고 해당 전통주 상세 화면으로 이동합니다.

#### 4. 경기술 지도와 도감
- 경기도 18개 시군 지도에서 지역별 전통주와 양조장, 지역 원료를 탐색할 수 있고, AR 체험을 마친 지역에는 스탬프가 등록됩니다.
- 완주한 술은 경기술 카드로 도감에 수집됩니다. 로그인 없이 브라우저에 저장하는 방식이라 개인정보를 받지 않습니다.

## 💻 Data Flow

```
[ 술BTI 추천 ]
사용자 응답(객관식 10 + 자연어 1)
  → POST /api/recommend  (Next.js Route Handler · 서버 전용)
      → scoring.ts     : 수치 축·키워드 축 점수화 + 하드 필터 → Top 10
      → prompt.ts      : system(소믈리에 역할) + 자유서술 + 후보 10종 속성 JSON
      → bedrock.ts     : Claude Sonnet 4.5 · output_config(json_schema) → [{id, reason}]
      → 검증           : id가 Top 10에 있는지 확인 (없으면 폐기)
      → 폴백           : 자격 증명 없음 / 호출 실패 시 규칙 기반 상위 3종
  → 추천 3종 + 추천 근거 렌더링 → 전통주 상세 → AR 양조 체험

[ AR 양조 체험 ]  ※ 전 과정 온디바이스
XR 세션(immersive-ar, hit-test/local, camera-access)
  → hit-test 조준 → 탭 → 양조장 앵커 고정
  → 카메라 텍스처(GPU) → 256px 렌더타깃 → CPU 리드백(16fps)
      → MediaPipe HandLandmarker → 관절 21개(landmarks / worldLandmarks)
      → gestures/stir/fan/knead : 히스테리시스 + 연속 프레임 확인 → 공정 진행도
  → Three.js 렌더 60fps (깊이 버퍼를 비운 뒤 장갑 손을 에셋 위 레이어로 합성)
  → 완주 → dex.ts : 도감 등록 + 지도 스탬프

[ 라벨 스캔 ]  ※ 전 과정 온디바이스
카메라 프레임 → 640×640 레터박스 → ONNX Runtime Web(YOLO11n)
  → 후보 8400 → conf 0.45 컷 → NMS → 1등 → 3프레임 연속 일치
  → 전통주 상세 화면으로 이동
```

## 🛤️ Roadmap

#### 2단계: 콘텐츠 확장
- AR 양조 체험을 경기도 전통주 전체로 넓히고, 삼양주·오양주의 덧술 분기와 증류 공정을 추가합니다.
- 라벨 인식 대상을 전 제품으로 넓히고, 학습 데이터를 촬영 환경별로 보강합니다.

#### 3단계: 양조장·판매처 연계
- 추천과 체험 직후 화면을 지역 판매처, 온라인 판매 채널, 양조장 방문 예약과 연결합니다.
- 계정 기반으로 도감과 취향 프로필을 저장해, 기기를 바꿔도 수집 기록이 이어지게 합니다.
- 양조장이 자기 술의 원료와 공정 데이터를 직접 등록하는 입점 도구와, 축제·박람회 현장용 부스 모드를 제공합니다.

#### 4단계: 전국·글로벌 확장
- 전통주 데이터베이스를 전국 단위로 확대하고 지역 관광 콘텐츠와 연결합니다.
- 다국어 서비스를 지원하고 해외 플랫폼과 연계해, K-푸드와 지역 특산물을 함께 소개하는 지역 문화 체험 플랫폼으로 발전시킵니다.
